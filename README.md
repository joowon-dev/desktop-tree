# 바탕화면 트리

지금 떠 있는 창마다 방울 셋(빨강·노랑·초록)이 크리스마스 트리에 달립니다. 맥 창 왼쪽 위의 그 단추들입니다.

- **빨강**을 누르면 그 창이 닫히고, 그 창의 방울 셋이 트리에서 떨어집니다
- **노랑**을 누르면 접히고(방울의 불이 꺼집니다), 다시 누르면 펴집니다
- **초록**을 누르면 화면에 꽉 차게 커지고, 다시 누르면 되돌아갑니다
- 방울에 마우스를 올리면 같은 창의 셋이 같이 켜지고, 어느 앱의 창인지 이름표가 뜹니다
- 트리는 **끌어서** 아무 데나 옮기고, **꼭대기 별을 끌어서** 크기를 정합니다(30%~160%)
- **받는 곳**: https://joowonkoh.com/playground/desktop-tree
- 맥 (Swift + WKWebView) · 윈도우 (.NET + WebView2)

## 설치와 제거

| | 설치 | 제거 |
|---|---|---|
| 맥 | dmg 를 열어 Applications 로 끌어 넣고, 처음 방울을 누를 때 **손쉬운 사용** 권한을 줍니다 (다른 앱의 창을 닫고 키워야 해서) | 메뉴바 아이콘 → 「바탕화면 트리 제거…」 — 앱·설정·로그인 항목·권한을 한 번에 치웁니다 |
| 윈도우 | `DesktopTree-win-Setup.exe` 를 실행합니다. .NET 9 데스크톱 런타임이 없으면 설치본이 받아서 깝니다 | 「설정 → 앱」 또는 트레이 아이콘 → 「바탕화면 트리 제거…」 |

새 버전이 나오면 메뉴에 「새 버전 설치」가 생깁니다. 누르면 받아서 갈아 끼우고 다시 뜹니다.

저장하지 않은 문서가 있는 창은 강제로 닫지 않습니다 — 그 앱이 평소처럼 저장할지 묻습니다.

## 만들기

```bash
npm install
npm start          # 맥에서 빌드하고 띄우기
npm test
npm run build:win  # 윈도우 셸 컴파일 (맥에서도 된다)
```

릴리스는 태그(`v*`)를 밀면 CI 가 만듭니다. 맥 배포본은 `./mac/notarize.sh` 로 공증한 것으로 덮어씁니다.
윈도우 셸은 CI 가 설치본을 실제 윈도우 러너에 깔고 방울을 눌러 창을 키우고·접고·닫아 본 뒤 제거까지 해 봅니다(`windows/smoke.ps1`).
